# AI·OSS 동아리 관리

[공개 웹사이트](https://dju-swcu.github.io/ai-oss-clubs/) · [웹사이트 운영 안내](WEBSITE.md)

[사업단 홈](https://github.com/DJU-SWCenteredUniversity) · [학생 프로젝트 공통 템플릿](https://github.com/DJU-SWCenteredUniversity/sw-project-template)

동아리 소개, 연간 활동, 공개 프로젝트와 성과를 함께 기록하는 공간입니다. **현재는 기본 구조를 마련한 단계이며 동아리 등록·승인·활동 수집 기능은 준비 중입니다.**

## 기본 구조

```text
clubs/2026/README.md              연도별 목록
clubs/<연도>/<동아리ID>/README.md   동아리 소개와 공개 프로젝트 링크
templates/club-profile.md        작성 양식
DEVELOPMENT.md                   개발·인계 안내
```

현재 실제 동아리 목록은 등록 전입니다. 새 연도에는 `clubs/<연도>/README.md`를 추가하고, 동아리별 소개는 양식을 복사해 작성합니다. 코드 저장소·주간 기록·발표 자료는 공개 가능한 원문 링크로 연결합니다.

자료는 학생팀이 제안하고 사업단 담당자가 공개 범위를 확인한 뒤 반영합니다.
